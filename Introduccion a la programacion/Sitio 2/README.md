# Sitio Web Empresarial - Librería Virtual "El Delirio"

Proyecto web profesional estructurado y optimizado para la librería en línea **El Delirio**.

## Estructura del Proyecto
- `index.html`: Página principal (Hero, recomendados, llamada a la acción).
- `catalogo.html`: Vista de productos con soporte para filtros.
- `libro.html`: Ficha detallada del producto con formatos EPUB, PDF y Físico.
- `carrito.html`: Carrito de compras y simulador de pagos.
- `nosotros.html`: Historia de la marca y mascota oficial.
- `contacto.html`: Formulario interactivo de ayuda y datos de contacto.
- `css/styles.css`: Estilos responsive con la paleta de colores oficial (`#3B1F5C`, `#1E90E0`, `#121212`, `#FFFFFF`).
- `js/main.js`: Lógica de navegación e interacción.

## Instrucciones de Instalación
1. Extrae el archivo ZIP en tu equipo.
2. Abre cualquiera de los archivos `.html` en tu navegador de preferencia.
